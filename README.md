 不用安裝、不用編譯、不需要網路，用瀏覽器打開就能玩。

## ✨ 這是什麼？

Pedal Circuit Lab 把經典破音效果器（Overdrive / Distortion / Fuzz）的電路原理、即時音訊模擬、波形分析、SPICE 模擬和一整套電子計算工具，全部塞進**一個 `.html` 檔**。

適合：

- 想搞懂效果器為什麼聽起來不一樣的DIY 玩家
- 學習運放、RC 濾波、削波與諧波失真的學生
- 想要隨手查電阻色環、分壓、LED 限流電阻的人

### 🎛️ 互動模擬器

- **三種失真模式**：TS808 軟削峰、RAT 硬削峰、Big Muff 雙級
- **三種削波二極體**：矽（約 0.6 V）、鍺（約 0.3 V）、LED（約 1.8 V）
- **旋鈕操作**：拖曳、滾輪、鍵盤方向鍵都可以
- 即時顯示 THD（總諧波失真）與整機頻率響應（輸入高通 + 增益級 + Tone 低通，隨旋鈕連動）
- 訊號源為內建合成的吉他 E 大和弦
- 亮色 / 深色主題切換

### 📐 電路庫

TS808 Overdrive 訊號路徑 · Fuzz Face 雙晶體管電路 · Op-Amp 單位增益緩衝器 · Op-Amp 乾淨推桿（Boost）· RAT 型硬削峰失真 · Big Muff 型 Fuzz · Tremolo 調幅

### 🔬 SPICE 模擬器

自己寫的小型求解器（MNA 建立方程式，非線性元件用牛頓法迭代），附 TS808 與 RC 低通兩個範例網表。

支援的元件：`R` `C` `L` `V`（DC / SIN / AC）`D` `Q` `U`（運放）。節點 `0` 為地，數值可用 `k`、`meg`、`u`、`n`、`p`。

```spice
* RC 低通，截止頻率約 1 kHz
V1 in 0 DC 0 SIN(0 1 1000) AC 1
R1 in out 1.59k
C1 out 0 100n
```

> 運放使用簡化模型（增益 1e5、輸出阻抗 100 Ω、受電源軌限制），二極體預設為 1N914 參數。時域固定分析 3 個週期，頻率響應範圍 10 Hz – 100 kHz。「試聽」需要有 `SIN` 來源（頻率上限約 4.8 kHz），以 48 kHz 計算 1 秒後播放。

## 🚀 快速開始

**方法一：直接開啟**

下載 `Pedal_Circuit_Lab_v8_categorized_5.html`，雙擊用瀏覽器打開即可。

**方法二：GitHub Pages**

1. 把 HTML 檔改名為 `index.html`（或保留原名，網址最後加上檔名）
2. 到倉庫的 **Settings → Pages**，Source 選 `main` 分支的根目錄
3. 等待部署完成後，用 Pages 提供的網址開啟

> 🔊 瀏覽器需要使用者操作後才允許發聲，請先到「互動模擬器」按下「開始發聲」。

## ⚠️ 使用須知

- 互動模擬器是依電路模型計算的**行為模擬**，用來理解原理與比較趨勢，不等於實際硬體的量測結果。
- 要自己組裝實體電路前，請用正式的 SPICE 軟體與實測確認元件值與供電。
